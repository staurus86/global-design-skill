## Full Description

Global Design Skill is an open-source design operating system for AI-assisted frontend work. It is not a prompt collection or a UI kit. It gives AI coding assistants structured design rules, UX blueprints, UI patterns, design tokens, specialized review agents, frontend handoff templates, and quality gates.

It works with Claude Code, Cursor, Codex, ChatGPT Custom GPTs, Windsurf, GitHub Copilot, and any AI assistant that can read repository context.

The system helps teams audit live pages, redesign generic AI-generated UI, create landing pages, build SaaS app shells, design admin panels, improve pricing pages, specify accessibility behavior, and produce implementation-ready frontend specs.
