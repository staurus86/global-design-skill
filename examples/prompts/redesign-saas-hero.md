# Redesign a SaaS Hero

Use this prompt to turn a generic AI-generated hero into a more specific product section.

```text
Use global-design-skill and redesign this SaaS hero:

[PASTE CURRENT HERO COPY / JSX / HTML / SCREENSHOT CONTEXT]

Constraints:
- avoid the default centered H1 + subtext + two equal buttons pattern
- define the target user and primary conversion metric first
- specify layout, grid, visual hierarchy, typography, CTA labels, proof, and mobile behavior
- include all interaction states for CTAs and links
- include accessibility notes and ARIA where needed
- return implementation-ready frontend instructions
```
