# Frontend Handoff Spec

Use this prompt to convert a rough feature idea into a developer-ready component or page spec.

```text
Use global-design-skill and write a frontend handoff spec for:

[DESCRIBE COMPONENT / PAGE / FLOW]

Include:
- user and job-to-be-done
- primary metric
- component anatomy
- variants and props
- idle, hover, active, focus, disabled, loading, empty, error, and success states
- responsive behavior
- design tokens
- ARIA and keyboard interaction
- acceptance criteria
- edge cases

The developer should be able to implement without asking clarification questions.
```
