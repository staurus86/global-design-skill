# Build an Admin Panel

Use this prompt when starting an operational interface, dashboard, CRM, analytics, moderation, or back-office product.

```text
Use global-design-skill and architect an admin panel for:

[DESCRIBE PRODUCT, USERS, DATA, AND MAIN WORKFLOWS]

Return:
1. information architecture
2. navigation model
3. core screens
4. table, filter, bulk action, empty, loading, and error states
5. keyboard and accessibility behavior
6. responsive rules for 390px, 768px, and 1280px
7. frontend handoff spec with component boundaries

Prioritize repeated-use efficiency over marketing-style presentation.
```
