# Audit a Live URL

Use this prompt when you want an AI coding assistant to review a live page, screenshot, or pasted HTML with Global Design Skill.

```text
Use global-design-skill and audit this page:

[PASTE URL, HTML, or screenshot context]

Return:
1. top 10 design problems ordered by severity
2. which quality gates fail
3. concrete layout, typography, color, interaction, accessibility, and responsive fixes
4. implementation-ready frontend notes
5. a final ship / revise / block verdict

Do not give generic advice. Tie every recommendation to the actual page.
```
