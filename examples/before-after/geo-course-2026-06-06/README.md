# GEO course landing — before → after

A redesign pass with the skill on a dark course landing page (a Russian-language GEO/AI-search course, geo-course.ru). The brief was a hero that didn't earn its space: a generic dark-SaaS template leaning on a decorative dashboard card and a countdown timer.

## What changed

- **One committed color story.** Teal-on-near-black (the default "dark SaaS" accent) → a single crimson hue on near-black with one signature radial glow, instead of a teal card competing with a teal CTA.
- **A metaphor replaced the data-slop.** The hero's decorative dashboard card (bar chart, fake list rows) → a glowing central node with radiating network lines — the *answer graph*: your brand as the node AI engines cite. That node is the One Memorable Thing the page is built around (Memorability Gate, `rules/00`).
- **Dark pattern removed.** The `06 : 05 : 10 : 12` countdown timer (fake urgency, a banned conversion pattern) is gone. Urgency now comes from a dated cohort ("10 июня"), not a ticking clock.
- **Price-pressure → course substance.** The `48 000 ₽` + timer card → a metadata strip that sells the product: level · modules · tools · start date.
- **Editorial hierarchy.** A bigger, tighter display H1, an eyebrow pill, a framing question block, and a real attributed testimonial (Google, 2026) replace the centered-text + floating-card split — E-E-A-T proof over decoration.
- **CTA hierarchy.** Two competing buttons → one red primary ("Записаться на курс") plus a quiet secondary text link ("Посмотреть программу курса").
