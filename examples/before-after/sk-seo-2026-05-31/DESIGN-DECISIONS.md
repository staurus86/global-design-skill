# Design Decisions — sk-seo.ru (2026-05-31)

Решения сессии с привязкой к принципам/gate скила. Каждая страница: что было → что стало → почему → как проверено.

## Метод верификации (общий для всех правок)
Локальный `python -m http.server` + Playwright. На каждую страницу: overflow-чек (docW vs vw на 390/768/1280/1440), axe-core 4.10.2 (wcag2a/2aa/21a/21aa), скриншот рендера. Деплой `bash deploy.sh --full` → smoke прода (curl 200 + grep разметки + Playwright 0 битых картинок).

## cases — Statement-band + editorial meta-spec
| | |
|---|---|
| **Было** | Сетка карточек: заголовок, текст, метрики, теги |
| **Стало** | Statement-бенто над сеткой («// Масштаб → От лендинга до 108 миллионов страниц» + 3 stat'а + портрет IMG_3379). Meta-блок `.case-meta` (Ниша/Масштаб/Статус) на 13 карточках |
| **Почему** | Статус-сигнал («Аудит сдан», «Свой проект») раньше нигде не читался; tier-масштаб даёт «насколько крупный клиент» для B2B-аудитории |
| **Ключевое решение** | **«Масштаб» = tier, не число.** 420K уже в заголовке и в метриках — третий повтор был бы водой. Tier (Enterprise/Mid-market/SMB/Свой проект) — новый сигнал |
| **Принцип** | Writing Standard «убирай лишнее», применённый к структуре, а не к прозе |
| **Проверка** | 0 axe, 0 overflow ×4; `components/03-cases-statement.jpg`, `04-cases-meta-block.jpg` |

## blog — card icons + unified CTA
| | |
|---|---|
| **Было** | Карточки листинга без иконок; 12 из 15 статей заканчивались **без CTA** |
| **Стало** | `.blog-card__icon` (52px) на 15 карточек по карте тема→иконка; 12 статьям добавлен единый inline audit-баннер + финальный CTA (реплика паттерна 3 флагманов) |

| **Проверка** | 0 axe, 0 overflow ×4; `components/10-blog-card-icons.png`, `11-blog-unified-cta.jpg` |

## Заметки на обновление скила

1. **Blueprint «бенто-редизайн».** Рецепт повторился 5 раз и устойчив: `grid-template-areas` + зелёная якорная ячейка (`var(--accent-green-dim)` бордер + `radial-gradient(var(--accent-green-glow))`) + мono-лейбл `// Метка` + стек на ≤900px. Кандидат в `blueprints/`.
2. **Gate «иконки несут смысл».** Добавить проверку: иконка маппится на тему элемента (не декоративный lucide наугад); на одной плоскости — без повторов.
3. **Price-anchoring через featured-ячейку** — паттерн для pricing/services: дороже-крупнее-первее.
4. **Editorial meta-spec** (мono-триада «label/value» с бордером) — переиспользуемый способ дать карточке «спеку», но **значения не должны дублировать** заголовок/метрики (tier вместо числа).
5. **Verify-before-tile в blueprint редизайна:** собрать паттерн на одной странице → axe+overflow+рендер → только потом тиражировать. Не доверять чужим/прошлым обещаниям верификации без артефактов на диске.
6. **Deploy-гигиена для no-build сайтов:** `cp -r` целых папок в deploy-скрипте тащит на прод бэкапы/сырьё; на SEO-сайте это дубли-контент по предсказуемым URL. Перед заливкой — выносить мусор из deploy-путей (move, не delete).
7. **Портрет как компонент:** 3/4 или 4:5 кроп в ячейке с `object-fit:cover` + `object-position` под лицо; квадрат для аватара/круга. Кроп подбирать предпросмотром (3 оффсета), не наугад.
