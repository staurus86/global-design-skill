# Before / After — sk-seo.ru (2026-05-30)

Второй before/after-пример для global-design-skill. Реальный прод-сайт (личный бренд SEO-специалиста, тёмная тема, vanilla HTML/CSS/JS, без билд-шага), проиндексирован — правки хирургические, URL и структура неизменны.

## Что в папке

- `before/` — 10 страниц × desktop (1440) + mobile (390), до правок.
- `after/` — те же кадры после правок.
- `DESIGN-DECISIONS.md` — таблица всех изменений с привязкой к принципам/gate скила + заметки для обновления скила.
- `_capture.mjs` — драйвер скриншотов (CDP через встроенный в Node WebSocket, full-page `captureBeyondViewport`, эмуляция `prefers-reduced-motion` чтобы контент ниже фолда был виден, `Network.setCacheDisabled`).
- `_jobs-before.json` / `_jobs-after.json` — списки кадров.

Как пересобрать: `python -m http.server 8000` из корня сайта → headless Chrome с `--remote-debugging-port=9222 --remote-allow-origins=*` → `node _capture.mjs _jobs-after.json`.

## Метод аудита

Две линзы: **дизайн** (Banned Patterns + 8 Quality Gates) и **анти-слоп** (Writing Standard владельца: сигнатурные слова RU/EN, конструкция «Это не X. Это Y.», em-dash, рубленый ритм). 6 субагентов прошли 28 страниц + общий CSS/JS-слой; находки сведены, дедуплицированы и исправлены по приоритету a11y → motion → анти-слоп → структура.

## Самые наглядные дельты (смотреть в скриншотах)

| Страница | Было | Стало |
|---|---|---|
| `404` | Изолированная страница: нет шапки, нет футера, 2 кнопки, `min-height:100vh` | Полная шапка + футер сайта, 4 пути наружу (Главная/Услуги/Инструменты/Блог), `100dvh`, skip-link |
| `contacts` | Цитата-манифест с декоративным side-stripe (banned) | Аккуратная карточка: фон + полный 1px border + radius |
| `services` | «Стоимость — по запросу» при видимых ценах; «SEO — марафон, не спринт» | «Цены — ниже, фиксированные»; «накопительный канал…» (диссонанс и клише убраны) |
| `about` | Дважды eyebrow `// Сообщество` подряд по смыслу | Вторая секция переименована в `// Хронология` / «Путь в SEO-сообществе» |

## Невидимые на скриншоте, но ключевые правки (a11y)

- Глобальный `@media (forced-colors: active)` фокус-блок — фокус-кольца теперь видны в Windows High Contrast на всех страницах.
- Формы (`seo-audit`, `llms-txt-generator`, `contacts`): `<label>`, `aria-live` на ошибки/прогресс/результат, `aria-invalid`+`aria-describedby` через `form.js`.
- `prefers-reduced-motion` guard для магнитных кнопок; `transition: all` → перечисление свойств.
- TOC статей: `:focus-visible`.

Полный список и обоснование — `DESIGN-DECISIONS.md`.

## Принципы скила, которые подтвердил этот кейс

1. Quality Gate 6 нужно усилить пунктом про **forced-colors** — `outline:none`+box-shadow проходит «на глаз», но мёртв в High Contrast.
2. **`aria-live` для динамики форм** — вынести в жёсткий чеклист.
3. **RU-аналог banned-копи** «Это не X. Это Y.» — добавить в Banned Copy (сейчас ловится только EN «Not X, it's Y»).
4. **404 как точка удержания** — кандидат в отдельный паттерн/gate.
5. **Кэш-бастер `?v=`** при правке split-CSS без билд-шага — обязательный шаг verify в blueprint редизайна.
