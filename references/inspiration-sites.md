## How to Use This File

**In a design session:**
1. Identify the block/section type you're building
2. Find the relevant category above
3. Open 2–3 reference sites
4. Note what works: typography, spacing, color, structure
5. Apply principles — never copy directly

**In reference-hunter agent:**
This file is the first lookup layer. If the request matches a listed site, fetch that URL directly. If not, use WebSearch to find fresh examples.
